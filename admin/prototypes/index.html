📝 使用说明

  • 所有原型均为独立 HTML 文件，双击即可在浏览器打开
  • 使用 Tailwind CDN，需联网加载样式
  • 原型包含可点击交互（弹窗、切换、确认），但无真实数据连接
  • 颜色方案：#E59303（主色）、#1D2129（深色背景）、#F3F4F6（页面底色）
  • 与现有 Beeznis 管理系统的 Ant Design 风格对齐
  • 对应 PRD v3.0 — 更新后需同步手册

币种设置

费率与限额 · 费率归属层级已由「币种」改为「通道 × 币种 × 清算网络 rails」 — 同币种不同 rails 成本与时效不同，配置即时生效

对外费率 = 客户账单口径；通道成本 = 上游结算口径，差额即毛利
本次变化：① 费率从「按币种」下沉到 通道 × 币种 × rails（USD 的 Wire / ACH / FedNow、EUR 的 SEPA / SEPA Instant、GBP 的 FPS / CHAPS 费率与成本各不相同）；② 新增 退回 / 退款费（对应 OpenPayd 上游 Cancelled）与 FX 兑换费（法币 → YASBee）；③ 限额明确到层级：平台级 ≤ 通道级 ≤ 客户级（客户级只可收紧）；④ 金额档位仍为线上实测口径（≤ 50,000 / > 50,000），费率数值为演示占位，定版前按线上配置核对。

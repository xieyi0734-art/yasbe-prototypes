# YASBE 管理端 — Card 模块账务功能 PRD

## v3.0 — 2026-06-03

> **核心变更**：将 v2.0 的 6 个子模块（费用结算/账单管理/交易流水/充值扣款/争议退款/财务看板）整合为 **3 个核心模块**，去重且职责清晰。

---

## 1. 产品概述

### 1.1 背景与目标

YASBE 管理后台 Card 模块已实现卡片生命周期管理，但账务功能分散且无独立入口。需构建统一的账务体系。

**目标**：让运营和财务人员通过 **3 个页面** 完成所有卡账务工作。

### 1.2 范围

- **平台**：YASBE 管理后台 Web 端
- **目标用户**：财务人员、运营人员、管理员
- **定位**：Card 模块下新增的 3 个子菜单入口

### 1.3 模块总览（3 个大模块）

```
Card Module（已有）
├── Card Management          ← 已有
├── ─────────────────────
├── 💰 1. 交易与结算         ← 合并：交易流水 + 费用结算 + 账单 → 一个页面
├── ⚡ 2. 充值/扣款与退款    ← 合并：充值扣款 + 退款 → 一个页面
└── ⚖️ 3. 争议工单           ← 独立：争议工单管理（问题驱动的，与日常账务不同）
```

**设计原则**：
- 日常记账查账 → 1 个页面搞定（交易与结算）
- 操作型功能 → 1 个页面（充值/扣款/退款）
- 异常处理 → 1 个页面（争议工单）

## 2. 模块详情

### 2.1 模块一：交易与结算

> 把**交易流水查询 + 费用结算列表 + 账单管理**揉到一个页面。

#### 2.1.1 核心思路

单页面，顶部一个 Tab 栏切换三个视图：

| Tab | 内容 | 对应旧模块 |
|-----|------|-----------|
| 📋 Transactions | 逐笔交易记录（充值/消费/退款/手续费） | 交易流水查询 |
| 📊 Settlement | 按周期（日/月）的费用汇总 | 费用结算 |
| 📄 Bills | 月度账单 | 账单管理 |

#### 2.1.2 Transactions Tab

```

### 2.2 模块二：充值/扣款与退款

> 把**充值/扣款操作 + 退款申请**合并到一个页面，上下两部分。

#### 2.2.1 页面布局：上半部「充值/扣款操作」

```
┌─ 手动操作 ──────────────────────────────────────────┐
│ 操作类型: [Recharge ▾]                                │
│ 选择卡片: [CRD-8A3F (john.doe@...) ⊕ 搜索]           │
│ 金额: [__________] USD                                │
│ 备注: [____________________________]                  │
│ 操作人: admin@yasbe.com (自动)                        │
│                       [Cancel] [🚀 Submit]            │
└──────────────────────────────────────────────────────┘
┌─ CSV 批量操作 ───────────────────────────────────────┐
│ [📎 Upload CSV]                                      │
│ 格式模板：Card ID | Amount | Type | Note              │
│ 预览: (上传后展示前5行)                                │
│                                                 [🚀 执行批量]│
└──────────────────────────────────────────────────────┘
```

**操作类型**：Recharge / Deduct / Adjust Balance
**校验规则**：
- Deduct 金额 ≤ 卡片当前余额
- 操作人和备注记录到审计日志

#### 2.2.2 页面下半部「操作与退款记录」

```
┌─ 操作/退款记录 ──────────────────────────────────────┐
│ 类型: [All ▾]  状态: [All ▾]  日期: [近30天 ▾]  [🔍] │
├────────┬────────┬────────┬────────┬──────┬──────┬─────┤
│ 编号    │ 类型   │ 卡片   │ 金额   │ 状态  │ 操作人 │ 时间 │
│ RF-001  │ Refund │ ...1234│ -$500  │ ✅完  │ admin │ 06-03│
│ OP-001  │ Deduct │ ...8A3F│ -$200  │ ✅完  │ admin │ 06-02│

                    [📥 Export CSV]
```

```
┌─ 发起退款 ─────────────────────────────────┐
│ 卡片: CRD-8A3F (john.doe@email.com)         │
│ 当前余额: $1,250.00                         │
│ 退款金额: [_______] (≤ $1,250.00)           │
│ 退款类型: [Balance Refund ▾]                 │

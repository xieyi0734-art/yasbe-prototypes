## 1. 背景与目标

### 1.1 背景

平台已经具备卡白标与法币 VA 的业务能力（Partner API + 开发者门户），但**缺少平台侧对租户的统一管理载体**：租户准入靠线下表格、费率靠人工邮件、品牌与域名靠工程临时改配置。本模块把租户从申请到结算的全生命周期收进系统。

### 1.2 目标

| # | 目标 |
|---|---|
| G1 | **准入线上化**：从邀请 / 申请到 `ACTIVE` 全流程线上留痕，审核 SLA 可度量 |
| G2 | **配置可控**：品牌 / 域名 / 邮件 / 费率在授权区间内由租户自助或在平台代改，平台只审不进产线 |
| G3 | **隔离可证明**：任一租户在任何入口都拿不到其他租户数据，且越权尝试有审计记录 |
| G4 | **计费可对账**：每笔费用的归属、定价快照、结算与争议全链路可追溯 |

### 1.3 范围

- **In**：租户准入 · 租户档案与生命周期 · 能力配售与额度 · 费率与计费 · 分润结算与对账 · 法币 VA 与开户作业 · 权限 / 隔离 / 审计 ·（后续）品牌配置与自定义域名邮件。
- **Out（本期）**：文档站「模式 A 渠道分销 / 模式 B 租户持牌白标主商户」两条路线；租户自带通道（Enterprise 选项）；定制 UI 与独立部署；存量历史租户数据迁移（存量不迁移）。

## 2. 名词表

| 名词 | 含义 |
|---|---|
| 白标租户 | 平台的客户（白标方），持有自己的品牌对外服务终端用户 |
| payment 模式 | 平台持牌做支付主体；资金先入平台主账户，再按周期结算至租户预存子账 |
| 租户子账（Sub-ledger） | 租户在平台内的付费与分润账户（预存、抵扣、消耗），**不折算多币种合计** |
| KYB | 租户准入的企业尽职调查（营业执照 / 法人身份证明 / 公司章程 / 地址证明 / 股东结构） |
| 能力授权（Capability Grant） | 逐租户开关：卡发行 / 虚拟账户 / 加密出入金 / 法币出入金 / API 接入 / 白标门户 |
| 额度（Quota） | 单次开卡上限、持卡人上限、人均卡数、交易限额、日 / 月累计限额 |
| 费率模板（Fee Plan Tier） | 一组费用类型的**基准价**，绑定租户套餐 |
| 费率 Override | 租户在授权区间内对基准价的 Markup / Discount；**低于平台底价直接拒绝** |
| 价格快照 | 计费事件发生时冻结当时价格；改价**不追溯**已发生交易 |
| 风控闸门 | 风险阈值与拦截规则；**仅平台可见可调，租户无入口、不可覆盖** |
| 开户费 | 为终端用户开 VA 时一次性收取：个人 VA $100 / 币种、企业 VA $1,000 / 币种，不支持减免 |
| 透视模式 | 平台侧跨租户查看的显式开关，进入即写审计 |

### 3.3 不可下放清单（红线，写进合约而非配置项）

1. 风险闸门阈值与拦截规则不可被租户覆盖或调低。
2. 平台上游成本、通道采购价、底价不可对租户可见。
3. 平台资金归集 / 托管钱包地址不向租户展示（属平台账本内容）。
4. 其他租户的任何数据（含聚合值）不可见。
5. 平台保留文案 key（合规声明、费用说明、风控口径）不可覆写。

### 3.4 多租户权限隔离

- **粒度**：行级隔离，`tenant_id` 为强制过滤维度；平台侧跨租户访问需显式「透视模式」开关，进入即写审计。
- **三层隔离**：数据隔离（租户 / 持卡人 / 交易 / 账单 / 日志按 `tenant_id` 分域）· 配置隔离（品牌 / 域名 / 邮件发件人 / 费率 Override 各自挂租户，互不继承）· 能力隔离（能力开关 + 额度 + 通道与币种授权逐租户授权）。
- **越权防护**：改写 URL / 请求体中的租户标识 → `403` + 审计告警（不得静默返回空集）；租户角色访问平台专属页（能力开关、风控、费率基准）→ 入口不渲染 + 接口拒绝；同一浏览器多租户切换 → 会话级租户上下文，切换即清缓存与预签名链接。
- **可见性边界**：平台侧按角色域收窄；租户侧永久只见自己（租户侧口径见租户业务台 PRD §3.3 三级守卫）。

## 4. 核心业务模型

### 4.1 租户生命周期状态机

```
DRAFT → SUBMITTED → UNDER_REVIEW
UNDER_REVIEW → INFO_REQUIRED → UNDER_REVIEW        （可多次循环，累计补件有上限）
UNDER_REVIEW → APPROVED → CONTRACT_PENDING → CONTRACT_SIGNED
CONTRACT_SIGNED → PENDING_FUNDING → ACTIVE
UNDER_REVIEW → REJECTED（不可修复：涉高风险行业 / 黑名单）
REJECTED → 冷却期后可重新提交（冷却时长待确认）
ACTIVE → SUSPENDED（欠费 / 合规事件）→ ACTIVE | TERMINATED
```

- 审核 SLA 从 `SUBMITTED` 起算，1–3 工作日；SLA 内未处理自动升级至平台超管。
- 驳回必须选原因码 + 自由文本：原因码区分**可修复**（文件不完整 / 信息不一致）与**不可修复**（涉高风险行业、股东或高管有不良记录），决定是否给重提入口。
- 补件回路 `INFO_REQUIRED`：逐条指定待补项、限 N 个自然日、超时自动关闭。

### 4.2 准入与上线就绪

- **两条入口**：平台超管「代客开通」与受邀企业「自助申请」（带租户标识与有效期的邀请链接，过期失效）。
- **KYB 材料**：营业执照 / 法人身份证明 / 公司章程 / 地址证明 / 股东结构（如有）；格式与清晰度自动检查；人工 + 机器审核。
- **合约**：Fee Plan 定价模板 / 结算周期（T+1 或 T+7）/ 最低预存要求 / 开卡与交易限额；双侧签章状态留痕。
- **支付网关绑定**：提交网关资料 → 归属验证 → 生效 / 失败退回。
- **API Key 发放**：Sandbox / Prod 两套（`sk_test_` / `sk_live_` 前缀区分），scope 勾选，**密钥仅创建时展示明文**。
- **Go-Live 校验**（置为 `ACTIVE` 的必要条件）：`KYB 通过 ∧ 合约生效 ∧ 网关已绑定 ∧ 预存 ≥ 最低 ∧ 域名与邮件（若启用）已生效`。

### 4.3 能力、额度与通道授权

- 能力矩阵逐项开关 + 生效时间：卡发行 / 虚拟账户 / 加密出入金 / 法币出入金 / API 接入 / 白标门户。
- 额度：单次开卡上限 · 持卡人上限 · 人均卡数 · 交易限额 · 日 / 月累计限额。
- 通道与币种授权：**USD = Bridge**；**EUR / GBP = OpenPayd（Linked Client）**；租户可用币种集合逐租户授权。
- 风控闸门只读展示给平台侧指定角色；阈值调整留审计，租户侧只看到结果口径。

### 4.4 计费与费率

| 项 | 口径 |
|---|---|
| 费用类型 | 开卡费（一次性 / 张）· 充值费（比例或固定）· 交易 Spread（bps）· 月费 / 席位费 · 提现费 · 退款手续费 · **法币 VA 开户费** |
| 模板与 Override | 平台定义模板（组数待确认）→ 按租户套餐分配 → 租户在授权区间内 Markup / Discount |
| 优先级 | `租户 Override > 租户模板 > 平台默认`；未授权调价的能力沿用模板价 |
| 底价保护 | 低于平台底价直接拒绝，提示下限并给自助申请提权入口 |
| 价格快照 | 计费事件发生时冻结价格；**改价不追溯**已发生交易 |
| 账单归属 | 平台 → 租户：平台服务费与成本；租户 → 终端用户：自有品牌出账（模板可配，平台不代出） |

**法币 VA 开户费**（与租户侧口径一致）：个人 VA **$100 / 币种**、企业 VA **$1,000 / 币种**、**不支持减免**；个人开通需终端用户钱包内有足额 USDT / USDC（支持以太链与波场链）覆盖开户费；企业开通暂不需要提前交费（记账后收取）。

### 4.5 结算与对账

- **分润**：平台留存 = 上游成本 + 平台 Markup；租户所得 = 终端定价 − 平台留存（是否含阶梯分成待确认）。
- **租户子账**：payment 模式下资金先入平台主账户，按周期结算至租户预存子账，用于抵扣各类费用与后续消耗。
- **结算单**：周期聚合、明细可下钻到交易号，状态 `PENDING → CONFIRMED → PAID → CLOSED`。
- **争议**：租户对某一笔发起争议 → 挂账冻结该笔 → 财务裁定 → 调整或驳回，全链路留痕。
- **欠费与降级**：余额不足扣月费 → 宽限期提醒（站内 + 邮件）→ 逾期降级（仅暂停增量动作：新开卡 / 新卡激活 / 新开 VA）→ 补缴自动恢复；**不自动终止租户**。

> 与租户侧的对账口径：租户业务台按**外扣模式实时扣减**展示（储备金逐笔扣费 + 月度账单）。管理端本节的「周期结算至子账」与之的映射关系见待确认 N1 —— 二者必须同一口径，否则租户看到的余额与平台结算单对不上。

### 4.6 法币 VA 与开户作业（平台视角）

- VA 口径：**一终端用户 × 一币种 = 一个 VA**，VA 开立即绑定通道；VA 状态：开立中 / 已开通 / 已停用。
- 平台侧可查全部租户的 VA 与开户申请，按租户维度聚合（本月入金 / 出金 / 余额）。
- 开户费按 4.4 的规则计收；开户失败要有失败原因与处置入口（重试 / 退回 / 联系租户）。
- 入金归因与挂账：VA 账号 → 附言 / reference → 上游流水号三路交叉，不唯一进挂账待认领（租户侧可只读 + 认领）。

## 5. 功能需求（按页面）

一期已落地页面：**租户列表 · 租户开通向导 · 租户详情总览 · 法币 VA · 开户记录 · VA 列表 · 交易流水查询 · 结算与对账 · 费率与计费 · 能力与额度 · 权限与审计日志 · 原型目录**。
（品牌配置、域名与邮件两页在结构大纲内属本模块，尚未出原型，见 §11。）

### 5.1 租户列表（M2）

- 统计条：全部 / 审核中 / 待补件 / 活跃 / 暂停。
- 筛选：状态、地区、计费套餐、创建时间；平铺表格。
- 行操作：进入详情、状态变更（暂停 / 恢复 / 终止；终止需二次确认 + 填原因 + 影响面提示）。
- 审核员可见但只读（仅审核队列视角）。

### 5.2 租户开通向导（M1）

代客开通一条线走完：企业基础信息（注册邮箱 / 公司名 / 法人 / 注册地址 / 联系人与电话）→ KYB 材料上传与逐项打标 → 审核结论（通过 / 驳回 / 要求补件）→ 电子合约签署（Fee Plan / SLA / 合作协议，双侧签章留痕）→ 支付网关绑定 → API Key 发放（Sandbox / Prod + scope）→ **Go-Live 校验**通过才置 `ACTIVE`。
向导内吸收 KYB 与合约步骤（不另开页面），可直接看到状态机当前位置与缺口清单。

### 5.3 租户详情总览

主体信息 · KYB 结论与材料 · 合约状态 · 网关绑定 · 子账与余额 · 能力开关摘要 · 域名与邮件健康态 · 关联账号（租户管理员与子账号的启停 / 重置 / 登录审计）· 变更入口（跳各子页）。

### 5.4 法币 VA（平台侧）

- 统计条 + 筛选（关键词 / 状态 / 币种 / 开立时间）+ 平铺表格：**VA 号 · 终端客户 · 类型 · 币种 · 状态 · 开户费 · 开立时间 · 本月入金 · 本月出金 · 余额 · 操作**；分页（共 N 条 · 每页 10 条）。
- 行操作：详情、入金指引。
- **开立法币 VA 弹窗**：开户费规则（原文，见 4.4）→ 客户类型（个人 / 企业）→ 币种（USD / EUR / GBP）→ 终端客户引用号 → 终端客户姓名 / 主体名 → 应缴开户费（随类型变化，只读）→ 终端用户钱包余额（USDT / USDC，可演示充足 / 不足）→ 开立原因 / 备注 → 生效时间（立即 / 指定时间）→ 提交开立。
- VA 详情 / 入金指引：收款账号 / 路由号 / 参考号**只对该终端客户展示**；平台侧归集账户与托管钱包属账本内容，不在此处向终端客户展示。

### 5.5 开户记录

开户申请流水（申请号如 `VA-OP-YYYYMMDD-NNNN`）：客户 / 代理、类型、币种、状态（开立中 / 已开通 / 已失败）、申请时间、完成时间；失败行可打开「开户失败处理」弹窗（失败原因、重试 / 退回 / 联系租户）。

### 5.6 交易流水查询

跨租户（透视模式下）按租户 / 时间 / 币种 / 业务类型 / 状态筛选；金额与手续费分列（外扣口径下手续费由租户承担）；可导出；点行看单笔详情。

### 5.7 费率与计费

费率模板管理（基准价，仅平台）· 租户费率 Override（授权区间内，低于底价拒绝）· 优先级与继承 · 价格快照规则说明 · 计费事件与费用明细查询（按租户 / 时间 / 费用类型 / 交易号，可导出）。

### 5.8 能力与额度

能力开关（逐项 + 生效时间）· 额度配置（开卡上限 / 持卡人上限 / 人均卡数 / 交易限额 / 日·月累计）· 通道与币种授权（USD=Bridge、EUR/GBP=OpenPayd）· 风控闸门只读展示 · 授权变更审计（操作人 / 前后值 / 生效时间）。

### 5.9 结算与对账

结算单列表（周期、金额、状态 `PENDING → CONFIRMED → PAID → CLOSED`）· 明细下钻到交易号 · 导出 · 争议发起与裁定（冻结单笔 → 裁定 → 调整 / 驳回）· 欠费与降级记录。

### 5.10 权限与审计日志

- 平台角色的权限配置（能力 × 角色）与不可下放红线提示。
- 审计日志：操作人（含角色与所属租户）· 动作 · 目标对象与租户 · 前后值 · 时间 · IP / 来源端 · 结果（成功 / 拒绝 / 越权）。
- 必录动作：准入结论、能力与额度变更、费率变更、品牌发布 / 回滚、域名与 SMTP 变更、结算确认 / 支付、争议裁定、状态变更、**开户费与 VA 状态变更**。
- 保留期与导出权限待确认。

### 5.11 品牌配置 · 域名与邮件（大纲内，未出原型，后续）

品牌资产（logo Light/Dark、favicon、登录页背景）· 主题 token（默认 `#FFCA00 → #FE5707`，仅允许区间内派生 + 对比度检查）· 文案字典（平台保留 key 不可覆写）· 邮件模板（邀请 / 验证 / 对账单 / 异常四类）· 品牌预览与发布（可一键回滚）· 自定义域名（唯一性与保留域校验 → CNAME + TXT 校验 → SSL 自动签发与续期）· 邮件发件域（SPF / DKIM / DMARC）与自带 SMTP（测试发信通过才可启用）· 失败一律**显式回退**到平台默认并告知。

## 6. 全局壳与交互规范

| 项 | 规范 |
|---|---|
| 导航 | 一级入口「白标租户管理」；下挂独立页面，**不做大 Tab 页**；租户域内的子页从租户详情进入并可返回 |
| 列表页 | 统计条 + 筛选区 + 平铺表格 + 分页；行内操作按钮按角色显隐 |
| 角色差异 | 平台侧按角色域收窄（审核员只见队列、财务只见结算域、风控只见风控域）；租户角色进入平台专属页 → 入口不渲染 |
| 透视提示 | 进入跨租户视角时顶部常驻「透视模式」标识 + 写审计 |
| 弹窗 | 二次确认用于：终止租户、能力 / 额度变更、费率变更、结算确认与支付、争议裁定、开立 VA 提交 |
| 文案 | 面向租户可见的文案不出现平台成本、底价、归集地址、风控阈值等平台专属项 |
| 数据 | 任何页面不得展示其他租户的数据（含聚合值） |

## 7. 风控与合规

1. **风控闸门不可下放**：阈值与拦截规则只允许平台在划定区间内调整并留审计；租户侧无入口、不可覆盖（写进合约）。
2. **风险扫描**：加密出入金按地址筛查（`risk_level ≥ 3` 拦截、0–2 放行），白标侧不可覆盖。
3. **KYB 材料**：加密存储、访问留痕，保留期按地区合规要求。
4. **密钥安全**：明文仅创建时展示；只存哈希；不进 URL / 日志 / 审计详情（审计只记名称与 ID）。
5. **SLA 与升级**：审核超 SLA 自动升级；驳回必须选原因码，区分可修复 / 不可修复。
6. **资金合规**：payment 模式下资金先入平台主账户；平台归集与托管钱包地址不向租户展示。

## 9. 成功指标

- 准入 SLA 达成率（SUBMITTED → 结论 ≤ 3 工作日）
- 自助率：租户在授权区间内完成费率 / 能力变更、无需人工邮件的比例
- 隔离断言：跨租户数据泄漏事件 = 0（含聚合值）
- 对账效率：结算单从 PENDING 到 CLOSED 的平均时长；争议单占比
- VA 作业：开立成功率、开户失败平均处置时长

## 10. 非功能需求

- **隔离性**：任何租户域查询不可出现跨租户数据（可测断言）。
- **可用性**：配置类变更不重启服务、不中断在途交易。
- **性能**：租户列表与结算单分页响应阈值（具体值待定）。
- **审计**：必录字段齐全、可导出、保留期按合规要求。
- **一致性**：平台侧与租户侧对同一笔费用的口径必须一致（价格快照为唯一真值）。

## 12. 验收标准（节选）

1. **准入**：`DRAFT` 租户在 KYB 通过、合约签署、网关绑定、预存达标、域名与邮件（若启用）生效之前，**不能**被置为 `ACTIVE`；缺少条件时 Go-Live 校验逐条列缺口。
2. **补件回路**：驳回项逐条可指定，租户侧看到待补清单；超期自动关闭；不可修复原因不给重提入口。
3. **隔离**：改写请求中的 `tenant_id` → `403` + 审计告警（不是空列表）；租户角色访问平台专属页 → 入口不渲染。
4. **计费**：低于底价的 Override 被拒绝并提示下限；改价后已发生交易的价格不变（价格快照）。
5. **结算**：结算单可下钻到交易号；争议发起后该笔被冻结、裁定后写审计；欠费只降级不终止。
6. **VA 作业**：按月维度能看到某租户的 VA 数、本月入金 / 出金笔数与余额；开户费按个人 / 企业类型正确取 $100 / $1,000；失败开户有处置入口。
7. **风控**：风控阈值租户侧无入口；阈值变更留审计（含前后值）。

开发者文档（7 页）

1️⃣

首页 / Welcome

能构建什么、平台四大核心组件、三种集成模式（渠道分销 / 白标主商户 / 聚合多租户）、入口分流。
2️⃣

快速开始

四步跑通首次调用：开通主体 → 取密钥 → 环境与鉴权（API Key / OAuth）→ 创建第一个客户；含请求约定与五个常见坑。
3️⃣

服务能力总览

白标能卖什么：8 大模块能力矩阵 + 端点 + 前置条件 + 沙盒可用性，含集成模式对照与能力边界（明确不做什么）。
4️⃣

API Reference

36 个端点清单 + 5 个端点的完整文档形态（字段表 / 多语言示例 / 响应 / 拒绝原因）+ 状态机枚举。
5️⃣

沙盒环境

沙盒怎么设计：自助开通、密钥形态、11 个模拟端点、测试数据、与生产的差异表、上线检查清单。
6️⃣

事件与通知

28 类事件清单、投递与重试策略、签名校验代码（Node / Python）、沙盒重投。
7️⃣

错误码与限流

错误响应结构、HTTP 语义、30+ 业务错误码、幂等语义、限流配额与重试策略。

参考基准

信息架构
Bridge API Docs（Get started / Guides / Platform / API Reference / Changelog）+ Interlace Developer Portal（模块化 AaaS / BaaS / CaaS / WaaS + 沙盒章节）
沙盒形态
Bridge：sk-test 前缀 + 独立基址 + simulate_kyc_approval；Interlace：api-sandbox 基址 + 门户自助取 clientId / clientSecret + 沙盒专属支持链清单
集成模式
Interlace MoR / Gateway / Distributor 三模式 → 映射为本平台的渠道分销 / 白标主商户 / 聚合多租户
本平台口径
能力清单来自 YASBe 公司简介与白标业务流原型；风险闸门口径取自 Merkle Science 钱包风险扫描 PRD（≥3 拦截）
📌
本原型中为占位设计的部分 端点路径与字段名为设计稿（尚无后端契约）；费率、走廊覆盖清单、配额数值、事件清单条目数以合同与最终 API 契约为准。

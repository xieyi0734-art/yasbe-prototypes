欢迎接入 YASBe 白标 API

YASBe 是 PayFi 支付金融基础设施。用一套 API，你就可以为你的终端用户提供 本地实时收款、跨境出款、货币兑换与稳定币桥、卡片发行、加密钱包出入金 以及内嵌合规风控 —— 无需自建本地实体、无需逐国开立银行账户、无需自行拼接多家通道。

四个基础对象贯穿全部能力模块。理解它们之后，任何业务流都只是组合调用。

选择你的集成模式

白标接入有三种模式，差别在于谁持有牌照、资金归谁、你的下游客户是否独立开户。 选错模式后期改造成本很高，建议在拿沙盒之前先确认。

🔗

模式 A · 渠道分销

你分销 YASBe 的 API 能力给你的下游商户，主体 KYB 与资金在 YASBe 侧，你赚取分润。

合规主责：YASBe · 上线最快
🏢

模式 B · 白标主商户

你是持牌或已具备合规能力的主商户，自己管理客户资金与风控，YASBe 提供通道与账务底座。

合规主责：共同 · 控制力最强
🌐

模式 C · 聚合多租户

你无牌或不愿持有客户资金，由 YASBe 持牌，你的每个下游客户获得独立账户与余额隔离。

合规主责：YASBe · 架构最复杂
ℹ️
模式决定你调用的接口范围 模式 A / C 下，客户开户、KYC 结果、资金归集由平台侧闭环，你主要调用收款、出款、卡片与事件接口； 模式 B 下你会额外获得子账户开立、余额划拨与结算管理接口。完整差异见 服务能力总览 · 集成模式对照。

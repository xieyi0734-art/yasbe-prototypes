API Reference

全部端点基址 https://api-sandbox.yasbee.com/v1 —— 用右上角环境切换可对照生产基址。所有端点返回 JSON，认证统一为 Authorization: Bearer <key>。

当前展示沙盒环境：api-sandbox.yasbee.com，示例密钥为 sk_test_ 前缀。

创建客户

POST /v1/customers 写操作 需 Idempotency-Key
创建一个终端客户。企业客户会同时进入 KYB 流程；沙盒中可用模拟端点直接置为通过。

请求体字段

字段类型必填说明
typeenum必填business / individual
namestring必填企业全称或姓名，须与证件一致（影响后续同名判定）
countrystring必填ISO 3166-1 alpha-2，注册国 / 国籍
registration_numberstring企业必填统一社会信用代码 / 公司注册号
emailstring必填用于接收通知与合规补件
phonestring建议填E.164 格式，含国家码
addressobject必填line1 / city / postal_code / country，注册地址子字段全部必填
kyb.business_typeenum企业必填企业类型，见枚举表
kyb.industrystring企业必填行业代码
kyb.websitestring企业建议无网站需在业务描述中说明
kyb.ubo[]array企业必填最终受益人：name / ownership_pct / country；持股 ≥25% 必须申报
metadataobject可选你的内部标识，原样回传，不参与风控

开立收款虚拟账户

POST /v1/virtual-accounts 写操作
为客户在指定币种与通道开出命名收款账户。返回的本地账号信息可直接展示给你的终端用户。
字段类型必填说明
customer_idstring必填归属客户
currencystring必填收款币种，如 USD / EUR / GBP
countrystring必填收款通道所在国家，决定分配的本地清算信息
account_namestring必填账户名（通常等于客户名）。同名判定以此字段为基准
purposeenum可选collection（默认）/ payout / treasury
metadataobject可选原样回传
cURLNode复制
curl -X POST https://api-sandbox.yasbee.com/v1/virtual-accounts \
  -H "Authorization: Bearer sk_test_9f2c…" \
  -H "Idempotency-Key: 1b8e4f60-…" \
  -d '{
    "customer_id": "cus_3f81a2bc9d",
    "currency": "USD",
    "country": "US",
    "account_name": "Shanghai Sunrise Trading Co., Ltd.",
    "purpose": "collection"
  }'
const va = await api.post('/v1/virtual-accounts', {
  customer_id: 'cus_3f81a2bc9d',
  currency: 'USD',
  country: 'US',
  account_name: 'Shanghai Sunrise Trading Co., Ltd.',
  purpose: 'collection'
});
响应 200复制
{
  "id": "va_7c29d10af5",
  "customer_id": "cus_3f81a2bc9d",
  "currency": "USD",
  "country": "US",
  "account_name": "Shanghai Sunrise Trading Co., Ltd.",
  "status": "active",
  "deposit_instructions": {
    "account_number": "9876543210",
    "routing_number": "021000021",
    "bank_name": "YASBe Partner Bank NA",
    "reference": "VA-7C29D10AF5"
  },
  "created_at": "2026-09-15T08:24:02.108Z"

一定把 reference 展示给付款方它是对账匹配的关键。终端用户漏填时，款项可能识别为匿名入账或进入人工处理。

发起出款

POST /v1/payouts 资金操作 需 Idempotency-Key
从客户余额付款到已登记的收款人。发起前请确认余额与同名校验均通过，否则会被直接拒绝。
字段类型必填说明
source_account_idstring必填扣款账户，余额必须覆盖金额 + 手续费
beneficiary_idstring必填收款人，须为同名且状态正常
amountstring必填十进制字符串，如 "1250.00"
currencystring必填扣款币种
target_currencystring可选到账币种；与扣款币种不同则自动走 FX
quote_idstring建议填锁价报价单，避免汇率波动
referencestring建议填你的业务单号，原样回传
metadataobject可选原样回传
cURL复制
curl -X POST https://api-sandbox.yasbee.com/v1/payouts \
  -H "Authorization: Bearer sk_test_9f2c…" \
  -H "Idempotency-Key: 3ac9f102-…" \
  -d '{
    "source_account_id": "acc_5b71c8e2",
    "beneficiary_id": "bene_2d90fa31",
    "amount": "1250.00",
    "currency": "USD",
    "target_currency": "CNY",
    "quote_id": "qt_88fe10c4",
    "reference": "INV-2026-0915-0442"
  }'

# 200 OK
{
  "id": "pay_9d3b7710e2",
  "status": "processing",
  "amount": "1250.00",
  "fee": "4.50",
  "target_amount": "8951.20",
  "target_currency": "CNY",
  "created_at": "2026-09-15T08:31:44.771Z"
}
⛔
常见拒绝原因（422）insufficient_funds · beneficiary_name_mismatch（非同名） · quote_expired · amount_below_minimum · corridor_not_supported

相关事件：payout.completed · payout.failed · payout.returned。

加密提现（含风险闸门）

POST /v1/crypto/withdrawals 资金操作 强制风控
把客户钱包余额提到外部地址。目标地址会先经过风险扫描，命中即拒绝，白标侧无法覆盖。
字段类型必填说明
wallet_idstring必填出金钱包
assetstring必填小写符号，如 usdt
networkstring必填TRC20 / ERC20 / BEP20 …
amountstring必填十进制字符串
to_addressstring必填外部钱包地址，必过风险扫描
memostring按链部分链必需（如 XRP / TON）
risk_scan_idstring可选你可先扫再提，复用同一扫描结果
请求复制
curl -X POST https://api-sandbox.yasbee.com/v1/crypto/withdrawals \
  -H "Authorization: Bearer sk_test_9f2c…" \
  -H "Idempotency-Key: 7be3104d-…" \
  -d '{
    "wallet_id": "wal_4a81c902",
    "asset": "usdt",
    "network": "TRC20",
    "amount": "500.00",
    "to_address": "TXk9yR2mVq7pLd4nBw8sJf1cZa6hEu3gQt"
  }'
200 通过403 拦截复制
{
  "id": "wd_2f0c91ba73",
  "status": "processing",
  "risk_scan": {"risk_level": 1, "decision": "allow"},
  "two_factor_status": "verified"
}
# risk_level 0–2 → 放行
{
  "error": {
    "code": "risk_level_exceeded",
    "message": "Destination address blocked by risk screening",
    "risk_scan": {"risk_level": 4, "decision": "block",
                   "categories": ["sanctions"]}
  }
}
# risk_level ≥ 3 → 拒绝，不可由白标侧覆盖
⛔
这条闸门是平台的合规底线请在你的产品里提前做提示：地址被拦截时引导用户更换收款地址，而不是提示「重试」。risk_level 相同的扫描结果在有效期内可复用（见沙盒页测试数据）。

开卡

POST /v1/cards 写操作
为持卡人开卡。虚拟卡即时生成可用；实体卡先进入制卡与邮寄流程，收到后需激活并设置 PIN。
cURL复制
curl -X POST https://api-sandbox.yasbee.com/v1/cards \
  -H "Authorization: Bearer sk_test_9f2c…" \
  -H "Idempotency-Key: 9e02ab35-…" \
  -d '{
    "cardholder_id": "chl_61d0f8a4",
    "type": "virtual",
    "currency": "USD",
    "spend_limit": {"daily": "2000.00", "monthly": "20000.00"},
    "mcc_policy": {"mode": "blocklist", "codes": ["7995", "6051"]}
  }'

# 200 OK
{
  "id": "card_88c1de40a7",
  "status": "active",
  "last4": "4242",
  "currency": "USD",
  "card_art": "your-brand-01",
  "created_at": "2026-09-15T08:40:11.902Z"
}

卡号、CVV 等敏感信息不通过 API 返回，仅可在你通过 PCI 认证后经专用接口获取，或由用户在我们提供的安全页面中查看。

统一交易查询

GET /v1/transactions 只读
跨模块统一查询交易：收款、出款、兑换、卡交易、链上出入金都在同一个列表里，便于对账。
查询参数取值说明
typedeposit / payout / conversion / card / crypto_deposit / crypto_withdrawal交易类型
statuspending / processing / completed / failed / rejected / returned状态过滤
customer_idcus_...按客户过滤
currencyISO 4217按币种过滤
created_from / created_toISO 8601时间范围
limit / starting_after1–100 / 游标 ID分页
cURL复制
curl "https://api-sandbox.yasbee.com/v1/transactions?type=deposit&status=completed&limit=50" \
  -H "Authorization: Bearer sk_test_9f2c…"

# 200 OK
{
  "object": "list",
  "has_more": true,
  "data": [
    {
      "id": "tx_51ac8890f2",
      "type": "deposit",
      "customer_id": "cus_3f81a2bc9d",
      "amount": "12000.00",
      "currency": "USD",
      "fee": "0.00",
      "status": "completed",
      "payer_name_match": "matched",
      "created_at": "2026-09-15T06:02:19.330Z"
    }
  ]
}

payer_name_match 取值 matched / mismatched / unknown，对应同名判定结果，可直接用于你的运营处理队列。

状态机与枚举

状态适用对象含义与后续
pending入金 / 客户 / 审核已受理未进入处理，可能等待人工或等待网络确认
processing出款 / 兑换 / 提现处理中，资金已冻结或已提交通道，不可撤销
completed全部终态，成功
failed出款 / 兑换 / 提现终态，资金已原路退回至来源账户
rejected入金 / 合规 / 提现终态，被规则或人工拒绝；提现场景含风险等级原因
returned出款 / 入金通道退回，通常 3–10 个工作日回到余额，可能产生通道费
ℹ️
状态只前进，不后退终态（completed / failed / rejected / returned）之后不会再变；returned 是独立终态而不是 failed 的一种，因为它带资金回退与费用差异。

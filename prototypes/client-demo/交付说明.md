# 客户端 Demo 最终交付

入口：<https://xieyi0734-art.github.io/yasbe-prototypes/prototypes/client-demo/index.html>

## 体验方式

目录提供登录注册、个人演示、企业演示三个入口。注册从空账户开始；演示账户预置体验资金。邮箱验证码可通过页面“一键填入”完成；出金身份验证器演示码为 246810。认证提交后可使用原型演示按钮模拟通过或退回。

数据仅存于当前浏览器，各账户隔离。所有资金、银行信息、卡片、报价及审核结果均为模拟数据，没有接入真实支付或认证服务。右上角可隐藏原型备注。

## 已交付范围

- 个人和企业：注册、登录、邮箱验证、密码重置及身份区分。
- 首页与认证：资产总览、银行与卡片独立认证、资料提交、审核和退回重提。
- 法币：USD/EUR/GBP 开户、收款信息、模拟入金、同名外部银行账户、出金及失败退款。
- 加密资产：USDT/USDC 充值、提现、网络选择及身份验证。
- 承兑：双向资产选择、演示报价、过期检查、双边余额与交易联动。
- 卡片：持卡人、开卡、开卡费扣除、卡片详情。
- 邀请与积分：模拟邀请、重复奖励拦截、积分账本、实物及数字商品兑换、订单完成。
- 交易记录：筛选、空结果、分页、详情和处理中结果模拟。
- 账户与安全：个人资料、身份验证器及退出。

## 三轮验证

使用 Microsoft Edge 无头浏览器执行真实页面交互，三轮共 115 项断言通过，页面 JavaScript 错误为 0。

1. 全流程：个人/企业注册、全模块路由、独立认证、三币种开户、入金、承兑、提现退款、持卡人与开卡、邀请、两类商品兑换、刷新后数据保留。
2. 边界与一致性：余额不足、负数金额、错误验证码、重复处理、同资产兑换、报价过期、积分不足、重复邀请、外部账户审核、交易筛选与分页、账户隔离、认证退回重提及密码重置。
3. 布局与入口：11 个模块在 390/768/1440 宽度下无文档级横向溢出，登录注册各阶段布局检测通过，目录入口及脚本错误检查通过。

补充修复：失败出金详情显示返还金额及返还后余额；邀请链接带入邀请码；统一原型备注与隐藏按钮。

## 验证限制

- 浏览器自动化通过不等于生产系统验收。接口级格式和精度校验、真实认证、银行/链上结算不在本原型范围。
- 截图已生成，但视觉分析服务连接失败，未声称人工视觉审查通过。
- 仓库通用交付闸门未全绿：旧品牌词表将“积分”判为禁词，本独立 Demo 保留当前业务名称；全仓登记和结构检查涉及其他未纳入本次交付的模块。未修改全仓规则或夹带其他模块改动。

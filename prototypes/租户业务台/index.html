范围与口径

业务范围
仅法币（USD / EUR / GBP）虚拟账户的开户、入金与出金；不含加密与卡片。
计费模式（外扣）
租户预存储备金，每笔出入金手续费从储备金扣减，不从终端用户本金中扣。
角色
管理员（全部）· 财务（资金与流水）· 研发（开发者配置），三档固定权限。

三份交付物的落点

交付物 1 · 导航与权限
左侧导航即权限树，切换左下角角色可直接验证隐藏与禁用。
交付物 2 · 三个核心页
储备金与账单 / 终端用户详情 / 交易流水（抽屉里拆出本金与手续费）。
交付物 3 · 防呆设计
API Key（密钥只显示一次）· Webhook 端点与投递日志（失败原因与自助排查）。

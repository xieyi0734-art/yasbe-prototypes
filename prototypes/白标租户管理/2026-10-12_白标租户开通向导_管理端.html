企业基础信息

与企业营业执照一致；作为线下 KYB 核对的主体基准。
前置条件：企业基础信息与地址信息为 KYB 必填项，缺一不可提交；提交后进入 SUBMITTED 状态，基础资料与合同归档后由平台线下完成 KYB 审核。

基础资料与合同

KYB 走线下审核：平台侧只登记企业基础资料 + 归档合同，不做线上材料审核。
PM 备注字段依据 F-103（企业信息：注册邮箱 / 公司名 / 法人 / 注册地址 / 联系人与电话）+ F-107（合同：合作协议 / Fee Plan / SLA 双签留痕）。合同四要素（编号 / 签署日期 / 生效日期 / 结算周期）齐备且资料登记完成后，才可进入 CONTRACT_SIGNED。

关键规则：① 取值优先级「租户定价 > 租户模板 > 平台默认」；② 低于平台底价保存即拒绝，并给出下限值；③ 所有计费事件取「事件发生时刻」的价格快照，改价不追溯已发生交易。
最低预存资金：Tier-B 要求预存 ≥ $50,000.00，用于抵扣开卡费与后续消耗；未达门槛不可置为 ACTIVE。

支付网关绑定

用于租户预存资金与周期结算；绑定前需完成归属验证。
PM 备注支付网关绑定为本次新增设计（占位，以最终 API 契约为准）：网关资料 + 归属验证 + 生效三段。验证失败可重发验证或更换网关；网关不可用时仅拦截增量动作，存量待激活卡提供「切换预存方式」旁路。
绑定状态：UNBOUND → PENDING_VERIFY（等待归属验证）→ VERIFIED；验证失败回到 PENDING_VERIFY 并展示失败原因与重发入口。
绑定失败的影响：预存无法到账 → 已发出但未激活的卡片无法激活。此处仅拦截新开卡与新卡激活，并在租户侧给出「切换预存方式（Bank Transfer / Crypto）」旁路。

自定义域名与邮件发件

可跳过；跳过时租户使用平台默认域与平台代发邮件，后续可在租户配置页补充。
DNS 校验：平台下发 CNAME 目标与 TXT 校验值 → 租户在 DNS 添加 → 平台轮询 + 手动「立即校验」→ 校验通过自动签发 SSL → ACTIVE。域名需全局唯一，平台主域及其子域不可绑定。
失效兜底：证书到期前 30 / 15 / 7 天多级提醒；续期连续失败降级到平台默认域并显式告知；DNS 记录被改动导致校验偏离时自动告警。
启用前置：发件域须先通过 SPF / DKIM / DMARC 记录校验，并通过「测试发信」才可启用。服务商拒绝服务（认证失败 / 配额超限 / 账号封禁）时自动回退平台默认发件人，并在租户后台与邮件页脚双处标注「当前为平台代发」。

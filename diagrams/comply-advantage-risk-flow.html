ComplyAdvantage 风控接入流程

实时 KYC/KYB 筛查 · C/A 持续监控（每 24h 自动重筛）· 客户信息同步

🔍 实时 KYC/KYB 风控

  • 创建客户 → AML 筛查 → 计算风险评分 → 分配风险等级（低 / 中 / 高 / 禁用）
  • NO_PROFILES：直通 STP；HAS_PROFILES：暂停 onboarding
  • 运营比对 profile 判定：通过 → 放行；拒绝 → 驳回

📡 C/A 持续监控（可开关）

  • 开启后每 24h 按最新配置自动重筛（非人工触发）
  • 可随时停用/重启用（PATCH /monitor），停用后不再重筛、不生成新警报
  • 新匹配自动生成 Case；CASE_CREATED / CASE_STATE_UPDATED Webhook 通知

🔄 客户信息同步

  • update-and-rescore：更新记录 + 自动重算风险分
  • 风险等级越阈值 → 可能触发重筛 / 新 case
  • 监控开关保持不变，可随时停用/重启用

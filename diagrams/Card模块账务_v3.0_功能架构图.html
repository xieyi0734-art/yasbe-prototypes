YASBE Card · 账务功能架构 v3.0

Module Architecture — Admin Console · 3 Modules

Module 1 · Transaction & Settlement

  • 交易流水逐笔查询 + 多维筛选
  • 按日/月的费用结算汇总
  • 月度账单生成与确认
  • 汇总统计 + 导出 CSV
  • 交易类型：Recharge / Consumption / Refund / Fee / Chargeback

Module 2 · Recharge/Deduct/Refund

  • 单笔充值/扣款/余额调整
  • CSV 批量充值/扣款
  • 退款申请 + 余额校验
  • 两级审批流（≤$100 / >$100）
  • 操作与退款历史记录 + 审计

Module 3 · Disputes

  • 争议工单列表 + 统计看板
  • 多维度筛选（状态/类型/时间/用户）
  • 工单详情 + 处理记录 + 时间线
  • 处理结果提交（WIN/LOSS）
  • 状态流转：OPEN → PROCESSING → RESOLVED → CLOSED

费用管理
🏦 卡片账户总览
主键 卡号 (CardNo) / 用户ID (UserId)
余额 当前余额 (Balance) / 冻结金额 (FrozenAmt)
统计 总充值 (TotalTopup) / 总消费 (TotalConsume)
状态 卡片状态 (Status) / 激活时间 / 过期时间
查看余额/状态 点击卡片
📋 交易流水查询
类型 充值 | 消费 | 退款 | 手续费 | 冻结/解冻
字段 交易ID / 卡号 / 金额 / 币种 / 时间 / 状态
筛选 时间范围 / 交易类型 / 金额区间 / 状态
状态 待处理 / 成功 / 失败 / 申诉中
💰 充值/扣款管理
手动 单笔充值(MANUAL_DEPOSIT) / 单笔扣款(MANUAL_DEDUCT)
批量 CSV导入 / 批量扣款 / 批量充值
审计 操作人(Operator) / 备注(Remark) / 操作时间
校验 余额校验 / 限额校验 / 重复校验
充值/扣款 → 写入交易流水 进入结算对账
🔄 结算与对账
平台账 平台交易记录 (PlatformTx) / 内部记账
渠道账 Interlace/发卡机构对账文件 (ChannelTx)
对账 逐笔匹配 / 金额核对 / 状态比对
状态 未对账 / 已对平 / 差异待处理 / 已调整
差异 差异金额 / 差异原因 / 处理人 / 处理方式
对账完成 → 计算手续费 处理差异
⚙️ 手续费管理
渠道费 支付网络手续费 (NetworkFee)
银行费 发卡机构处理费 (BankFee / Interchange)
平台收入 用户侧费用 - 渠道成本 = 平台毛利
统计 总手续费 / 净收入 / 费率区间
⚠️ 异常与退款处理
标记 标记异常交易（原因、截图、凭证）
退款 发起退款 → 金额返还 → 冲销流水
调整 余额调整(ADJUST) / 冻结/解冻(FREEZE/UNFREEZE)
审核 异常单流转: 提交 → 运营初审 → 财务复核 → 完成
确认收入 → 聚合报表 异常数据进入专用报表
📊 报表与分析
余额报表 日/月余额汇总 / 账户余额分布 / 余额变动趋势
收入/成本 总充值 / 手续费收入 / 渠道成本 / 净收入
对账报表 对账汇总 / 差异明细 / 对账完成率 / 日/月报告
异常报表 异常交易统计 / 退款率 / 处理时效 / 分类分析
导出 CSV / Excel / PDF 导出，支持定时推送
